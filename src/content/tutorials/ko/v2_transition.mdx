## 중학교 및 고등학교 교사를 위한 p5.js v2 전환 가이드

중학교에서 수업하다 보면, 늘 사용하던 도구의 버전이 바뀌는 것이 신경 쓰일 때가 있습니다. 이미 익숙한 수업 자료와 활동이 있다면 더 그렇습니다.

p5.js v2로 넘어가는 일이 걱정된다면, 이 가이드가 도움이 될 것입니다. 학생들이 하던 작업 대부분은 이전과 같은 방식으로 그대로 작동합니다.

여러 중학교 및 고등학교 p5.js 커리큘럼([CS4All Creative Web](https://blueprint.cs4all.nyc/curriculum/creative-web/), [CS4All Introduction to Computational Media](https://blueprint.cs4all.nyc/curriculum/intro-to-computational-media/), [CodeHS Digital Art with p5.js](https://codehs.com/course/p5-js/overview), [CSinSF Creative Computing](https://sites.google.com/sfusd.edu/csinsfcreativecomputing/home?authuser=0), [Processing Foundation Art + Code](https://processing.github.io/art-plus-code/codeAsCreativeMedium-intro/))을 검토해 보니, p5.js v1에서 v2로 넘어갈 때 손봐야 하는 부분은 여러 커리큘럼에서 공통적으로 두 가지로 나타났습니다.

* 입력 이벤트
* 에셋 불러오기

[다른 v2 업데이트](https://github.com/processing/p5.js-compatibility)(곡선 도형, 텍스트 측정, 유틸리티 함수 변경 등)도 있지만, 이런 내용은 보통 중학교나 고등학교 커리큘럼에 많이 포함되지 않으므로 실제 수업에 미치는 영향은 크지 않습니다.

이 가이드에서는 중학교와 고등학교 수업에서 실제로 자주 접하게 되는 변경 사항만 다룹니다. p5.js v2에 맞춰 코드를 수정하는 방법과, 오래된 스케치에 호환성 애드온이 필요한 경우도 함께 살펴봅니다.

꼭 필요한 내용만 골라 담았으니, 이 문서를 통해 p5.js v2를 빠르게 익히고 수업에 자신 있게 활용해 보세요.

## 웹 에디터에서 버전 선택하기

대부분의 경우, 교사와 학생 모두 별다른 수정 없이 p5.js v2를 사용할 수 있습니다.

다만 기존 스케치를 열었을 때 예상과 다르게 동작할 수 있습니다. 이전 학년도 학생 작품이나 p5.js v1 기준으로 만든 커리큘럼 예제가 이런 경우에 해당합니다. 이럴 때는 다음과 같은 방법을 사용할 수 있습니다.

* 이 가이드의 예시를 참고해 **스케치를 업데이트**할 수 있습니다.
* **[호환성 애드온](https://docs.google.com/document/d/1Dk5nqLYL_ryw_7xjADhgPHOi5N6xkC9v_FM2vOz_Hc8/edit?tab=t.ocxorofdcw24)을 사용**할 수 있습니다.
* 에디터에서 해당 스케치를 **p5.js v1으로 다시 전환**할 수 있습니다.

![p5.js 웹 에디터의 버전 선택 목록 스크린샷](../images/2.0/v2-libman.png)

## 입력 이벤트

입력 이벤트는 p5.js v2에서 가장 먼저 차이를 체감하기 쉬운 부분입니다. 학생들은 입력 이벤트를 다음과 같이 활용할 수 있습니다.

* 버튼을 누르거나 상태를 바꾸기
* 마우스를 누른 상태에서 그림 그리기
* 키를 눌렀을 때 변수 바꾸기
* 캔버스를 지우거나 저장하기
* 화살표 키로 게임 캐릭터를 움직이기

아래 내용에서는 중학교 및 고등학교 수업에서 자주 쓰는 입력 이벤트 코드와 p5.js v2에서 달라진 점을 살펴봅니다.

### 마우스 클릭

p5.js v1에서는 특정 마우스 버튼을 확인할 때 보통 다음과 같이 작성했습니다.

```js
if (mouseButton === RIGHT) {
  // 원하는 동작 실행 (p5.js v1)
}
```

p5.js v2에서는 다음과 같이 작성합니다.

```js
if (mouseButton.right) {
  // 원하는 동작 실행 (p5.js v2)
}
```

**참고:** [mouseButton](/ko/reference/p5/mouseButton/)

<Callout title="교사용 메모">
v2에서 `mouseButton`은 `left`, `right`, `center` 같은 불리언 속성을 가진 객체로 바뀌었습니다. 그래서 여러 버튼을 동시에 감지할 수 있습니다. 그림 그리기 도구처럼 버튼마다 다른 동작을 주고 싶을 때 특히 유용합니다.
</Callout>

### 키보드 입력

p5.js v1에서는 중학교 및 고등학교 커리큘럼 대부분이 다음과 같은 코드로 키 입력을 확인했습니다.

```js
if (keyIsPressed) {
  if (key === UP_ARROW){
    // 원하는 동작 실행 (p5.js v1)
  }
}
```

`keyIsPressed`는 수업 초반에 배우는 간단한 불리언 변수이고, `key ===` 구문도 학생들이 이미 알고 있는 비교식과 비슷해 설명하기 수월합니다.

p5.js v2에서는 다음과 같은 방식이 권장됩니다.

```js
if (keyIsDown(UP_ARROW)) {
  // 원하는 동작 실행 (p5.js v2)
}
```

`keyIsDown()`은 v1과 v2 모두에서 안정적으로 동작하고, 여러 키를 동시에 확인할 수도 있어서 현재 권장되는 방법입니다.

**참고:** [keyIsDown](/ko/reference/p5/keyIsDown/)

### 호환성 애드온(선택 사항)

새로운 수업에서는 위의 v2 코드를 사용하는 편이 좋습니다.

오래된 스케치를 코드 수정 없이 계속 사용하고 싶다면 **Data & Events** 호환성 애드온으로 v1 동작 방식을 복원할 수 있습니다.

## 에셋 불러오기

학생들이 학습을 이어 가다 보면 이미지, 소리, 글꼴 같은 에셋을 추가해 스케치를 더 개성 있게 꾸미고 싶어 할 수 있습니다.

p5.js v1에서는 이를 `preload()`로 처리했습니다.
p5.js v2에서는 `setup()` 안에서 `async`와 `await`를 사용합니다.

### p5.js v1의 `preload()`

p5.js v1에서 `preload()`는 내부의 항목이 모두 불러와질 때까지 스케치 실행을 멈추는 역할을 했습니다.

```js
let img;

function preload(){
  // v1에서는 preload()를 사용했지만 v2에서는 사용하지 않습니다.
  img = loadImage("cat.jpg");
}

function setup(){
  createCanvas(100, 100);
  image(img, 0, 0);
}
```

### p5.js v2의 `async`와 `await`

p5.js v2에서는 더 이상 `preload()`를 사용하지 않습니다. 대신 `async setup()` 안에서 `await`를 사용해 에셋을 불러옵니다. 이 방식은 이미지, 소리, 글꼴, 그 밖의 파일에도 똑같이 적용됩니다.

```js
let img;

async function setup() {
  createCanvas(100, 100);
  
  // 파일이 모두 불러와질 때까지 기다립니다.
  img = await loadImage("cat.jpg");
  
  image (img, 0, 0);
}
```

## 호환성 애드온

호환성 애드온은 p5.js 웹 에디터에서 선택적으로 켤 수 있는 보조 파일입니다. 코드를 업데이트하지 않아도 오래된 p5.js v1 스케치를 p5.js v2에서 비슷하게 동작하게 해 줍니다.

온라인에서 찾은 예전 스케치나 p5.js v1 방식의 오래된 수업 자료를 그대로 써야 한다면, 이 애드온이 필요할 수 있습니다.

새로운 수업에서는 앞으로 계속 지원될 버전을 학생들이 익힐 수 있도록 v2 방식으로 코드를 작성하는 편이 좋습니다.

* 입력 이벤트에는 **Data & Events** 호환성 애드온을 사용합니다.
* 에셋 불러오기에는 **Preload** 호환성 애드온을 사용합니다.

![사용자가 1.x 호환 애드온 라이브러리를 켜고 끌 수 있는 p5.js 에디터의 라이브러리 관리 탭 스크린샷](../images/2.0/v2-addons.png)

여기에는 **Shapes** 호환성 애드온도 보이지만, Shapes API 변경은 중학교나 고등학교 수업에서 흔히 다루는 내용과는 거리가 있습니다. 주로 더 고급 사용자 정의 도형에 해당하므로, 대부분의 교사에게는 필요하지 않습니다.
