description: >
  <p>Creates a screen reader-accessible description of the canvas.</p>

  <p>The first parameter, <code>text</code>, is the description of the
  canvas.</p>

  <p>The second parameter, <code>display</code>, is optional and can be
  <code>LABEL</code> or

  <code>FALLBACK</code>. The third parameter, <code>lang</code>, is optional and
  sets the language

  of the description for screen readers. However, if only the optional 'lang'

  parameter is passed, it will be treated as the second optional parameter and

  the default option 'FALLBACK' will be used as the display.</p>

  <p>Read

  <a href="/learn/accessible-labels.html">Writing accessible canvas
  descriptions</a>

  to learn more about making sketches accessible.</p>
