description: >-
  <p>Draws a <a href="/reference/p5/p5.Geometry"><code>p5.Geometry</code></a>
  object to the canvas.</p>

  <p>The first parameter, <code>model</code>, is the

  <a href="/reference/p5/p5.Geometry"><code>p5.Geometry</code></a> object to
  draw.

  <a href="/reference/p5/p5.Geometry"><code>p5.Geometry</code></a> objects can
  be built with

  <a href="/reference/p5/buildGeometry/"><code>buildGeometry()</code></a>. They
  can also be loaded from

  a file with <a
  href="/reference/p5/loadGeometry/"><code>loadGeometry()</code></a>.</p>

  <p>Note: <code>model()</code> can only be used in WebGL mode.</p>

  <p>A model with several materials, such as a character with separate skin,

  shirt, and shoe materials, keeps each material's own colors and textures.

  The call to <code>model()</code> is the same whether the model has one
  material or

  many, so a model made in software such as Blender appears the way it was

  exported.</p>
