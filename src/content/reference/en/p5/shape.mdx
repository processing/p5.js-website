description: >-
  <p>Draws a <a href="/reference/p5/p5.ShapeCollection/">p5.ShapeCollection</a>
  onto the canvas.</p>

  <p>You can draw/replay a previously recorded shape object onto the screen
  canvas

  using the <code>shape()</code> function. This enables a retained graphics
  pipeline

  similar to Processing <code>PShape</code>.</p>

  <p>When rendering an imported SVG or recorded shape with <code>shape()</code>,
  you can

  also pass position coordinates <code>(x, y)</code> and an <code>options</code>
  configuration object

  to control alignment and scaling directly without manually wrapping calls

  in <code>push()</code>, <code>translate()</code>, <code>scale()</code>, and
  <code>pop()</code>.</p>

  <p>Options include:</p>

  <ul><li><p><code>align</code>: Alignment mode for positioning:</p>

  <ul><li><code>CORNER</code> (default): Aligns the top-left corner of the
  shape's coordinate

  bounds to <code>(x, y)</code>. Normalizes any non-zero viewBox
  offsets.</li><li><code>CENTER</code>: Centers the shape's bounding box
  precisely at <code>(x, y)</code>.</li><li><code>VIEWBOX</code>: Preserves raw
  SVG coordinates without bounding box offset

  normalization, translating the origin <code>(0, 0)</code> directly to
  <code>(x, y)</code>.</li></ul></li><li><p><code>scale</code>: Scaling factor
  to apply:</p>

  <ul><li>Uniform scaling: A single number (e.g. <code>{ scale: 0.5 }</code> or
  <code>{ scale: 2 }</code>).</li><li>Non-uniform scaling: An object with
  independent axes

  (e.g. <code>{ scale: { x: 1.5, y: 0.8 } }</code>).</li></ul></li></ul><p>When
  <code>x</code>, <code>y</code>, <code>scale</code>, or non-zero alignment
  offsets are applied, <code>shape()</code>

  automatically wraps transformations inside <code>push()</code> and
  <code>pop()</code>. Subsequent

  drawing operations on the canvas remain completely unaffected.</p>
