  <p>Creates a 4x4 matrix inside a p5.strands shader callback.</p>

  <p><code>mat4()</code> is the same function as

  <a href="/reference/p5/transform3D/">transform3D()</a>, named the way it is in
  GLSL.</p>

  <p>Passing a 3x3 matrix to <code>mat4()</code> extends it with the identity
  matrix, which

  turns a 2D transform into a 3D one that leaves the z-axis alone.</p>

  <p>Note: <code>mat4()</code> can only be used inside a p5.strands shader
  callback.</p>
