description: >-
  <p>Downloads the sketch or a recorded shape as an SVG file. Supports two
  modes:</p>

  <p>Deferred frame export: queues an automatic SVG export for a frame

  using p5.js lifecycle hooks (<code>predraw</code> and <code>postdraw</code>):

  <code>saveSVG([filename])</code></p>

  <p>Shape recording automatically starts at <code>predraw</code> and stops at
  <code>postdraw</code>,

  exporting the complete SVG immediately after the frame finishes drawing.

  When called in <code>setup()</code>, it captures the first frame of
  <code>draw()</code>. When

  called in <code>draw()</code> or event handlers (<code>keyPressed</code>,
  <code>mousePressed</code>), it

  schedules and captures on the next frame.</p>

  <p>Direct shape export: immediately exports an existing

  <a href="/reference/p5/p5.ShapeCollection/">p5.ShapeCollection</a>:

  <code>saveSVG(record, [filename])</code></p>

  <pre><code class="language-js example">function setup() {
    createCanvas(300, 300);
  }


  function draw() {
    background(220);
    fill(0, 120, 255);
    circle(mouseX, mouseY, 50);
  }


  function keyPressed() {
    if (key === 's') {
      // Queues export for the next frame
      saveSVG('interactive-frame.svg');
    }
  }</code></pre>
