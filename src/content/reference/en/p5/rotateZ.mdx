description: >-
  <p>Rotates the coordinate system about the z-axis in WebGL mode.</p>

  <p>The parameter, <code>angle</code>, is the amount to rotate. For example,
  calling

  <code>rotateZ(1)</code> rotates the coordinate system about the z-axis by 1
  radian.

  <code>rotateZ()</code> interprets angle values using the current

  <a href="/reference/p5/angleMode/">angleMode()</a>.</p>

  <p>By default, transformations accumulate. For example, calling
  <code>rotateZ(1)</code>

  twice has the same effect as calling <code>rotateZ(2)</code> once. The

  <a href="/reference/p5/push/">push()</a> and <a
  href="/reference/p5/pop/">pop()</a> functions

  can be used to isolate transformations within distinct drawing groups.</p>

  <p>Note: Transformations are reset at the beginning of the draw loop. Calling

  <code>rotateZ(1)</code> inside the <a href="/reference/p5/draw/">draw()</a>
  function won't cause

  shapes to spin.</p>

  p5.strands. Inside a shader

  callback, it takes a transform created with

  <a href="/reference/p5/transform3D/">transform3D()</a> as its first parameter,
  as in

  <code>rotateZ(myTransform, PI / 4)</code>. Instead of turning the coordinate
  system,

  it returns a new transform with the turn added on and leaves the one passed

  in untouched, so the result has to be assigned back. This does the same

  thing as calling <a href="/reference/p5/rotate/">rotate()</a> on a 3D
  transform.

  Angles are always in radians inside a shader. The finished transform is

  applied to a position with

  <a href="/reference/p5/transformPoint/">transformPoint()</a>. See its
  reference for

  a more in-depth explanation of how that works. The following example turns

  each instance of a bar a little more than the one before it.</p>

  let count = 5;


  function setup() {
    createCanvas(200, 200, WEBGL);
    myShader = buildMaterialShader(fanOut);

    describe('Five red bars in a row, each turned more than the last.');
  }


  function fanOut() {
    worldInputs.begin();
    // Spread the bars across the canvas, turning each one a bit more.
    let spacing = width / count;
    let t = transform3D();
    t = translate(t, (instanceIndex - (count - 1) / 2) * spacing, 0, 0);
    t = rotateZ(t, instanceIndex * PI / 12);
    worldInputs.position = transformPoint(t, worldInputs.position);
    worldInputs.normal = transformNormal(t, worldInputs.normal);
    worldInputs.end();
  }


  function draw() {
    background(220);
    lights();
    noStroke();
    fill('red');
    shader(myShader);
    instances(count).box(6, 40, 6);
  }</code></pre>
