description: >-
  <p>Rotates the coordinate system about the y-axis in WebGL mode.</p>

  <p>The parameter, <code>angle</code>, is the amount to rotate. For example,
  calling

  <code>rotateY(1)</code> rotates the coordinate system about the y-axis by 1
  radian.

  <code>rotateY()</code> interprets angle values using the current

  <a href="/reference/p5/angleMode/">angleMode()</a>.</p>

  <p>By default, transformations accumulate. For example, calling
  <code>rotateY(1)</code>

  twice has the same effect as calling <code>rotateY(2)</code> once. The

  <a href="/reference/p5/push/">push()</a> and <a
  href="/reference/p5/pop/">pop()</a> functions

  can be used to isolate transformations within distinct drawing groups.</p>

  <p>Note: Transformations are reset at the beginning of the draw loop. Calling

  <code>rotateY(1)</code> inside the <a href="/reference/p5/draw/">draw()</a>
  function won't cause

  shapes to spin.</p>

  p5.strands. Inside a shader

  callback, it takes a transform created with

  <a href="/reference/p5/transform3D/">transform3D()</a> as its first parameter,
  as in

  <code>rotateY(myTransform, PI / 4)</code>. Instead of turning the coordinate
  system,

  it returns a new transform with the turn added on and leaves the one passed

  in untouched, so the result has to be assigned back. Angles are always in

  radians inside a shader. The finished transform is applied to a position

  with <a href="/reference/p5/transformPoint/">transformPoint()</a>. See its
  reference

  for a more in-depth explanation of how that works. The following example

  gives each instance of a box its own turn to arrange them in a ring.</p>

  function setup() {
    createCanvas(200, 200, WEBGL);
    myShader = buildMaterialShader(placeOnRing);

    describe('Ten red cubes in a tilted ring, turning like a carousel.');
  }


  function placeOnRing() {
    worldInputs.begin();
    // Each cube gets its own spot on the ring, which turns over time.
    let angle = instanceIndex * TWO_PI / count + millis() * 0.001;
    let t = transform3D();
    t = rotateX(t, 0.7);         // tilt the whole ring toward the viewer
    t = rotateY(t, angle);       // turn to this cube's spot on the ring...
    t = translate(t, 65, 0, 0);  // ...and step out to the ring's edge
    worldInputs.position = transformPoint(t, worldInputs.position);
    worldInputs.normal = transformNormal(t, worldInputs.normal);
    worldInputs.end();
  }


  function draw() {
    background(220);
    lights();
    noStroke();
    fill('red');
    shader(myShader);
    instances(count).box(18);
  }</code></pre>
